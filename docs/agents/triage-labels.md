# Triage labels

Use these strings in each local issue's `Status:` line.

| Canonical role  | Local status    | Meaning                                      |
| --------------- | --------------- | -------------------------------------------- |
| needs-triage    | needs-triage    | Needs evaluation                             |
| needs-info      | needs-info      | Waiting for information                      |
| ready-for-agent | ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation                |
| wontfix         | wontfix         | Will not be implemented                      |

When a skill refers to a triage role, use its local status from this table. Claiming and completion follow the lifecycle rules in [the tracker conventions](issue-tracker.md).
